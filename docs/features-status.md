# 📊 סטטוס פיצ'רים בפרויקט (Feature Status)

> **עדכון אחרון:** 29/01/2026

## 📝 הנחיות עדכון (Update Instructions)

מסמך זה משמש כ"מקור האמת" (Single Source of Truth) לניהול המשימות והסטטוס בפרויקט.

1. **באגים ומשימות בביצוע**: כל באג חדש, תיקון עיצוב או פיצ'ר שנמצא בפיתוח פעיל - יופיע בראש המסמך תחת פרק זה.
2. **תכנון עתידי**: רעיונות לפיצ'רים שטרם הוחל בפיתוחם יופיעו תחת "פיצ'רים מתוכננים".
3. **היסטוריה וביצוע**: פיצ'ר שהושלם יועבר לפרק "פיצ'רים מיושמים", יסומן ב-✅, ויתווסף לו תאריך סיום/גרסה.

## ⏸️ פיצ'רים מתוכננים (Planned)

### 🏫 מצב כיתה/קבוצה (Class Mode)

- [ ] **התאמה לשימוש בבתי ספר**: אפשרות להגדיר המערכת עבור "כיתה" ולא "ילד/ה".
- [ ] **שינויי טקסטים**: התאמה ללשון רבים.
- [ ] **ניהול רשימות שיתופי**: אולי?

### 🔄 סנכרון ונתונים (Sync & Data)

- [ ] **טעינת רשימות מקובץ מקומי**: ייבוא מתוך קובץ (JSON) לגיבוי ידני או העברה offline.
- [ ] **סנכרון בזמן אמת (Real-time)**: סנכרון ביצוע משימות בין קליינטים (ללא שמירת PII בשרת). טכנולוגיות לבחינה: WebRTC / WebSocket.
- [ ] **סנכרון ללא חשבון גוגל**: חיבור בין מכשירים באמצעות Pairing Code.
- [ ] **תמיכה במכשירים מנותקים**: פתרון למכשירים "כשרים" ללא שירותי גוגל.
- [ ] **אופטימיזציית גיבוי**: פירוק הגיבוי לדרייב למניעת העלאה חוזרת של תמונות.
- [ ] **בדיקת זהות**: בדיקה האם 2 גרסאות זהות למניעת סנכרון מיותר.

### 🖼️ עיצוב וממשק (Design & UI)

- [ ] **ערכות נושא (Themes)**: השלמת יישום ערכות נושא ותמיכה במצב כהה/בהיר.
- [ ] **העלמת ממשק ניהול**: מצב "נקי" לגמרי עם טאגל להצגת אנשי צוות/כותרת.
- [ ] **רשימה במסך מלא**: אפשרות לצמצם את גודל הרשימה כך שתיכנס כולה במסך (Fit to Screen).
- [ ] **וידג'ט רשימות קומפקטי**: עיצוב מחדש לוידג'ט ניהול רשימה.
- [ ] **יצירת לוח בגרירה**: הכנת לוח חדש בקלות על ידי גרירה ממחסנית (Drag from template).

### 🧩 מאגר פעילויות (Activity Bank)

- [ ] **בנק תמונות/פעילויות**: הצגת כל התמונות שהועלו בעבר ככרטיסים מוכנים לשימוש, כולל איזור עריכה וניהול.

### 📺 מסך טלוויזיה (Dashboard)

- [ ] תצוגה ייעודית למסך גדול בבית (Passive Display).
- [ ] "מי נמצא באיזו פעילות כרגע" בזמן אמת.

### 📱 תאימות (Compatibility)

- [ ] **דפדפן קיוסק**: פתרון הבעיה שפופאפ לא נפתח (למשל בחיבור חשבון).

### 📚 משחק קריאה

- [ ] מודול נפרד ללימוד קריאה בשיטה חזותית.

### ☁️ גיבוי ענן ציבורי

- [ ] העברת האפליקציה למצב "Published" ב-Google Cloud Console.
- **סטטוס**: מוכן טכנית - דורש רק שינוי הגדרות.
