# טקסטים ליצירת TTS (Text-to-Speech)

מסמך זה מרכז את כל הטקסטים שמשמשים בממשק הילד ובפעילויות, לצורך הקלטתם ב-TTS.

## 1. ממשק הילד (קבוע)

**מקור:** `src/lib/data/texts.ts` (TEXTS_CHILD)

| מזהה (Key)                    | טקסט (עברית)               | הערות                                      |
| :---------------------------- | :------------------------- | :----------------------------------------- |
| `USER_SELECTOR_TITLE`         | מי משתמש בלוח היום?        | כותרת מסך כניסה                            |
| `APP_TITLE_PART1`             | סדר יום                    | חלק 1 של שם האפליקציה                      |
| `APP_TITLE_PART2`             | ויזואלי                    | חלק 2 של שם האפליקציה                      |
| `LOADING_APP`                 | טוען סדר יום...            | מסך טעינה                                  |
| `PRAISE_ALUF` (בן)            | אתה אלוף!                  | חיזוק לבן                                  |
| `PRAISE_ALUF` (בת)            | את אלופה!                  | חיזוק לבת (לרוב זהה בהגייה אך שונה בכתיב?) |
| `WELL_DONE`                   | כל הכבוד!                  |                                            |
| `ALL_DONE_MESSAGE`            | סיימת את כל המשימות להיום! | הודעת סיום יום                             |
| `DEFAULT_GREETING_WITH_COMMA` | בהצלחה,                    | ברכת ברירת מחדל                            |
| `TODAY_NO`                    | היום אין                   | משמש במשימות שבוטלו                        |
| `FINISHED_PREFIX`             | סיימת את                   | קידומת להודעת סיום משימה                   |
| `NOW_PREFIX`                  | עכשיו,                     | קידומת למשימה נוכחית                       |
| `CHANGE_LABEL`                | שינוי!                     | חיווי שינוי בסדר יום                       |
| `NOW`                         | עכשיו                      |                                            |
| `DONE`                        | בוצע                       |                                            |
| `WHO_WILL_BE_WITH_US`         | מי יהיה איתנו היום?        | כותרת אזור אנשים                           |
| `COMMUNICATION_BOARD`         | לוח תקשורת                 |                                            |
| `OPEN_COMMUNICATION_BOARD`    | פתח לוח תקשורת             | Tooltip/ARIA                               |
| `CLOSE`                       | סגור                       |                                            |
| `FLOATING_WINDOW_TITLE`       | חלון צף                    | כותרת                                      |
